# Accessibility — WCAG 2.2 AA

Automated checks (axe on every frame, both themes) catch about half of these. The rest is on you.

## 1. Contrast

- Text: 4.5:1. Large text (≥ 24 px, or ≥ 18.7 px bold — in practice `text-2xl`, or `text-xl font-bold`): 3:1.
  `text-lg font-semibold` is normal text and needs 4.5:1.
- UI boundaries that identify a control (input borders, checkbox outlines) and meaningful icons: 3:1.
- Token pairs from `tokens.md` already pass. Contrast problems come from leaving those pairs: muted text on
  tinted backgrounds, `opacity-*` on text or icons, text over images. Disabled controls are exempt.
- Color never carries meaning alone: a status has a label, an error has text, a required field has `required`.

## 2. Focus

- Every interactive element shows focus: `focus-visible:outline-2 focus-visible:outline-offset-2
  focus-visible:outline-focus` (text inputs: `focus-visible:-outline-offset-1`).
- Never remove an outline without that replacement.
- Focus not obscured (2.4.11): sticky headers, footers, bulk action bars and toasts must not cover the
  focused element. Lay them out with flex so content scrolls beside them, or add `scroll-pt-*` /
  `scroll-pb-*` on the scroll container equal to the sticky bar's height.
- Tab order follows visual order. No `tabindex` greater than 0.

## 3. Target size

- At least 24×24 px for every pointer target (2.5.8); 44×44 px on touch: `pointer-coarse:size-11` for icon
  buttons, `pointer-coarse:h-11` for buttons and inputs.
- A target may be smaller only if a 24 px circle centered on it doesn't overlap another target (the
  spacing exception). Links inside running text are exempt.
- Every `hover:` has an `active:` state for touch feedback.

## 4. Semantics

- `<button type="button">` for actions, `<a href>` for navigation. Never a clickable `<div>`.
- One `<h1>` per page, headings in order, landmarks (`header`, `nav`, `main`, `aside`, `footer`).
- Tables: `<table>`, `<th scope="col">`, a `<caption>` (can be `sr-only`), sortable headers with `aria-sort`.
- Lists are `<ul>` / `<ol>`. Groups of controls are `<fieldset>` with `<legend>`.
- `<html lang>` = the UI language; foreign-language fragments get their own `lang`.
- Widgets follow WAI-ARIA Authoring Practices: dialog (`role="dialog"`, `aria-modal`, `aria-labelledby`),
  tabs (`tablist` / `tab` / `tabpanel`), menu, combobox, listbox, grid.

## 5. Names and descriptions

- Every control has a visible `<label for>`. A placeholder is not a label.
- Icon-only buttons: `aria-label` («Закрыть», «Удалить сделку»). Decorative SVG: `aria-hidden="true"`.
- Hint and error text are linked with `aria-describedby`; an invalid field has `aria-invalid="true"`.
- Images: meaningful `alt`, or `alt=""` when decorative. Avatars with a visible name: `alt=""`.

## 6. Forms

- Required fields: `required` attribute plus a visible marker explained once at the top of the form.
- Error text says what is wrong and how to fix it, placed under the field.
- Long forms: an error summary at the top after submit, with links to each invalid field.
- Inputs get `autocomplete`, `inputmode` and `type` that match the data (`email`, `tel`, `decimal`).
- Don't ask for the same information twice in one flow (3.3.7) — prefill it.
- Authentication (3.3.8): paste and password managers work; no puzzle CAPTCHAs or memory tests.

## 7. Dragging, timing, motion

- Dragging (2.5.7): every drag has a single-pointer alternative — a «Переместить в…» menu on kanban cards,
  «Вверх / Вниз» buttons for sortable lists, inputs next to sliders.
- Toasts with an action pause while hovered or focused. Errors and anything the user must act on are never
  shown only in a toast. An undo toast is never the only way back — the item is also recoverable (archive).
- Animations only with `motion-safe:` (`motion-safe:animate-pulse`, `motion-safe:transition-transform`).

## 8. Reflow and zoom

- At 320 px width and at 200% text size nothing is cut off. No fixed heights on containers with text.
- Truncated text has the full value in `title` or a tooltip; never truncate the only copy of an error.
